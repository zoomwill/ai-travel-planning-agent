# Master Prompt for Codex

```text
You are helping me reconstruct a multi-agent AI travel planning project from an architecture
specification. I am a complete programming beginner.

Read AGENTS.md and every file in docs, but do not edit anything yet.

The source material is architecture plus pseudocode, not the original repository. Preserve
the intended behavior while using current supported library APIs. Never invent successful
tests, performance metrics, external API results, or production readiness.

We will work one numbered phase at a time. For each phase:
1. explain the goal in beginner language,
2. inspect existing code,
3. propose the smallest change,
4. identify files and dependencies,
5. implement only that phase,
6. run formatting, linting, type checks, and tests,
7. fix failures,
8. show changed files and manual verification commands,
9. update implementation notes for source/API deviations,
10. stop and wait.

Start by reading and summarizing the repository. Then wait for my Phase P00 prompt.
```
